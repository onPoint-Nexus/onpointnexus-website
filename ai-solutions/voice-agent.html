Frequently Asked

Questions buyers ask before they sign.

Can it really sound like our brand voice?

Yes. We clone a voice using a 3-10 minute reference recording from anyone you designate (founder, existing brand voice actor, or synthetic professional voice). The result is nearly indistinguishable from the reference in normal conversation.

How many calls can it handle simultaneously?

There is no hard concurrency limit. the system scales horizontally on demand. Clients have run 100+ concurrent calls during peak windows with no degradation.

Is the latency actually real-time?

Response latency averages 700-900ms end-to-end, which reads as conversational. It is not perceptibly delayed.

Does it integrate with our CRM?

Yes. it writes leads to Google Sheets, HubSpot, Salesforce, or any CRM with a webhook. We build the connector in the initial deployment.

Can it hand off to a human?

Yes. When intent signals a high-value opportunity or the AI cannot answer confidently, it transfers to a live agent via Twilio call routing or drops a Slack alert with a callback request.
